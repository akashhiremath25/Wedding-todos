# S&A Wedding Todo 💍 (Native Android)

A fully native Android application for **Shradha & Abhishek's wedding** itinerary and task management.

## Features
- **Native Itinerary**: real-time task list synced with Firebase Firestore.
- **Google Sign-in**: Secure authentication using native Google Play Services.
- **Role-based Access**: Admin and Guest permissions managed via Firestore.
- **Smooth Animations**: Built with Jetpack Compose with fluid transitions and list animations.
- **Native Pickers**: Calendar and Clock selectors for event scheduling.
- **Self-updates**: Automatically checks for new releases on GitHub.

## Tech Stack
- **Language**: Kotlin
- **UI**: Jetpack Compose (Material 3)
- **Backend**: Firebase Firestore & Firebase Auth (Native SDKs)
- **Architecture**: MVVM
- **Build System**: Gradle Kotlin DSL

## Getting Started
1. Ensure `google-services.json` is in the `app/` directory.
2. Build and run via Android Studio.
